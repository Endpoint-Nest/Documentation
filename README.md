## What is Endpoint Nest?
Endpoint Nest is a service that will be available to the public, planning to let developers build and manage APIs using provided (optional) SDKs in (potentially) different languages, dashboards and other tools. Developing, maintaining and debugging APIs takes time, which we aim to solve! Endpoint Nest aims to serve a large range of APIs, from public to private, from small to large, from simple to complex.

### Why is it being built?
Endpoint Nest, as a service, aims to make developing and managing API systems easier, quicker and more simple. It aims to give as much freedom as possible through lots of planned tools such as:
- Endpoint management
- Endpoint overviews
- Custom data types
- Databases (storage)
- Debugging modes
- Custom rules
- Workers
- SDKs
- _and more..._
